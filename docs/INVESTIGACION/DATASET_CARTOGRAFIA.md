# Cartografía empírica de cognición contextual

**Estado:** investigación activa  
**Fecha:** 2026-10-07  
**Propósito:** seleccionar datasets humanos abiertos para pasar de la validación sintética de S003 a evidencia empírica y construir una biblioteca reutilizable para Saussure-Quantum, Psyche Simulacra y Hanna.

## 1. Principio rector

El programa filosófico del laboratorio incluye, entre otros, Descartes, Nietzsche, Heidegger, Jung y Campbell.

Estos autores funcionan como marcos de interrogación y fuentes de problemas filosóficos. No constituyen evidencia empírica ni premisas que los datos deban confirmar.

La secuencia metodológica es:

filosofía → pregunta fenomenológica → fenómeno humano observable → dataset → baseline clásico → modelo alternativo → comparación cuantitativa → resultado → conocimiento reutilizable.

No se debe invertir esta secuencia para acomodar los datos a una teoría previa.

## 2. Pregunta científica general

¿Puede construirse un modelo computacional de la cognición humana en el que percepción, significado, memoria, contexto y decisión sean estados dinámicos, y en qué fenómenos los modelos quantum-like proporcionan una representación superior o más parsimoniosa frente a modelos clásicos apropiados?

La investigación debe admitir resultados positivos, negativos y ambiguos.

## 3. Familias prioritarias

### P0-A — Orden de preguntas

**Fuente:** Wang & Busemeyer y replicaciones posteriores.

Fenómeno: la respuesta conjunta puede depender del orden de presentación de dos preguntas.

Aplicación inmediata: S003.

Objetivos:
- reconstruir tablas conjuntas A→B y B→A;
- calcular residual QQ;
- reproducir pruebas estadísticas;
- comparar con baselines clásicos predeclarados;
- evaluar ajuste fuera de muestra cuando la estructura de datos lo permita;
- registrar explícitamente los datasets donde las hipótesis del modelo QQ no se cumplen.

Importante: la literatura incluye un dataset Rose–Jackson cuyo QQ residual es significativamente distinto de cero y cuya estructura contiene información adicional entre preguntas. Este caso debe conservarse como control de límites del modelo, no descartarse.

### P0-B — Asociación libre multilingüe

**Fuente:** Free Association Database, 62 estímulos, 7 idiomas, 14 países.

Datos publicados: 1.439 participantes y 223.786 respuestas; existen datos brutos y procesados.

Objetivos:
- construir redes asociativas por individuo, idioma y estímulo;
- estudiar frecuencia y diversidad de asociaciones;
- estimar estabilidad intra/intercultural;
- identificar clusters y transiciones;
- comparar representaciones vectoriales, grafos y modelos contextuales;
- reservar la comparación con categorías junguianas/campbellianas para una etapa posterior y explícitamente exploratoria.

### P0-C — Percepción bistable

**Fuente:** Hardstone et al., Long-term priors influence visual perception through recruitment of long-range feedback.

Fenómeno: Necker cube y Rubin face-vase, con cambios perceptuales reportados por el participante.

Datos: cohorte ECoG de 14 pacientes; cohortes sanas presenciales y online; existe un dataset conductual online público.

Objetivos:
- reconstruir secuencias de perceptos;
- estimar duraciones y tasas de transición;
- estudiar sesgos perceptuales individuales;
- comparar modelos independientes, Markov, modelos de estado y modelos contextuales;
- utilizar neurodatos solamente como etapa posterior de validación.

## 4. P1 — Segunda ola

- Three Terms Task: benchmark semántico de 10.107 tríadas y validación conductual de 2.255 tríadas.
- Source Monitoring: atribución de fuente de recuerdos y modelos de decisión.
- Confidence Database: confianza/metacognición a gran escala.
- ADMC: competencia de decisión, framing, riesgo y reflexión.
- Semantic Priming: influencia del contexto lingüístico previo.
- Forward Flow: dinámica de asociaciones en pensamiento libre.
- PPIR: replicaciones multicéntricas de efectos de juicio moral.

## 5. P2/P3 — Validación posterior

- cognición social multimodal;
- moralidad + EEG;
- MOFOMIC;
- naturalistic language;
- OpenNeuro;
- datasets EEG/fMRI/iEEG específicos.

La neurofisiología no debe sustituir a la demostración conductual.

## 6. Priorización para futuros sistemas

Cada dataset se evaluará en dos dimensiones independientes.

### Valor científico

- calidad del diseño;
- acceso a datos;
- nivel trial-level;
- tamaño muestral;
- posibilidad de reproducir resultados;
- hipótesis falsables;
- existencia de baselines apropiados.

### Valor arquitectónico

- utilidad para representación de estados;
- contexto;
- memoria;
- incertidumbre;
- significado;
- transición entre estados;
- potencial para Psyche Simulacra;
- potencial para Hanna.

El valor arquitectónico nunca puede aumentar artificialmente el grado de evidencia científica.

## 7. Hipótesis de transferencia

Los resultados suficientemente robustos podrán transformarse en componentes reutilizables:

fenómeno humano
→ representación matemática
→ parámetros observables
→ dinámica
→ incertidumbre
→ memoria/contexto
→ componente cognitivo artificial.

Psyche Simulacra y Hanna deben consumir conocimiento validado, no asumir como verdad los marcos filosóficos utilizados para formular las preguntas.

## 8. Regla contra la confirmación sesgada

No se programarán arquetipos, estructuras narrativas o supuestos filosóficos como si fueran hechos descubiertos.

Para Jung y Campbell:

datos
→ estructura emergente
→ cluster/narrativa recurrente
→ comparación con categorías existentes
→ evaluación de ajuste.

No:

arquetipo
→ clasificación forzada
→ confirmación.

## 10. Estado actual

La cartografía preliminar es suficiente para iniciar la fase de ingestión técnica.

No se considera que ningún dataset haya demostrado todavía una estructura quantum-like.

El primer objetivo empírico es reproducir y auditar S003 sobre datos humanos reales.
